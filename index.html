About

Android's what I do.

Kotlin developer based in Nepal. I've shipped around 20 Android apps over five years — some for startups, some for freelance clients, some solo. One of them has 100K+ downloads.

Mostly Kotlin and Jetpack Compose — MVVM, clean architecture, Firebase. I've worked on consumer apps, a fintech app, a video chat app, and currently picking up Kotlin Multiplatform on real projects. I write code I'm not embarrassed to hand off.

Lately I've been moving toward being tech-agnostic. If you need something in React Native, Flutter, or Compose Multiplatform, I can work with that too — I lean on AI-assisted development to ship across stacks without pretending I've spent years in each one.
